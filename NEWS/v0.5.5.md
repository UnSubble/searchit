# Searchit v0.5.5

Release Theme: Execution Control & Engine Stability

Searchit v0.5.5 introduces highly requested execution control mechanics and hardens the internal accounting invariants for greater UI accuracy.

### New Features
- **Interactive Pause & Resume**: Added native pause and resume functionality. You can now press `p` during any active `scan` or `fuzz` execution to safely halt the workers without losing session context.
- **Enhanced Telemetry**: Implemented a sliding-window tracker for real-time requests-per-second (Req/s) monitoring, alongside improved request retry tracking and latency monitoring.

### UX Improvements
- **Configuration Unification**: The initial configuration report emitted at the start of `scan` and `fuzz` commands has been unified and simplified for a cleaner startup appearance.
- **Terminal Rendering**: Addressed a regression where the main progress dashboard would improperly duplicate or leave trailing artifacts when transitioning to full-screen views (like the statistics report).

### Engine Stability & Correctness
- **Accounting Invariants**: Hardened worker accounting to ensure that queued jobs are precisely decremented during all network or filter error cases, preventing "zombie jobs" from keeping the queue artificially high.
- **Fuzz Execution Re-architecture**: Internal fuzzing structures were refactored for more robust concurrent scheduling and more accurate result processing.
