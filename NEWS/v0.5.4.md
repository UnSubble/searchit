# Searchit v0.5.4

Release Theme: Diagnostics & UX Polish

Searchit v0.5.4 focuses strictly on refining the update experience by eliminating false positives and clarifying contextual operation messages.

### UX Improvements
- `searchit update` now correctly outputs `UNAVAILABLE` when news cannot be fetched, rather than falsely implying an internal verification failure.
- `searchit update` statuses now preserve context (e.g., `UPDATE COMPLETED` or `ROLLBACK REQUIRES MANUAL ACTION`) instead of generically indicating `INSTALLATION COMPLETED`.

### Correctness
- Searchit now properly resolves canonical symlink paths during installation discovery. Aliased executables (like `/bin/searchit` resolving to `/usr/bin/searchit`) no longer falsely trigger multiple-installation warnings.
