# Searchit v0.7.0

Release Theme: Final-Response Redirects, Strategy-Aware Extensions & CLI Parity

Searchit v0.7.0 introduces final-response redirect inspection via `--only-redirects` across both scan and fuzz commands, strategy-aware candidate extension traversal across eager, BFS, DFS, priority, and adaptive modes, candidate and wordlist encoding, enhanced HTTP connection controls, and significant CLI cleanup and SemVer comparison fixes.

### Added

- **`--only-redirects` for `scan` and `fuzz`** — follows redirect chains to their terminal destination and reports only candidates that triggered at least one redirect, displaying the final response status code and effective path rather than intermediate 3xx hops.
- **Strategy-aware extension traversal** — candidate extension variants (`-e`, `--ext`) now participate directly in scan and fuzz traversal strategies (`eager`, `bfs`, `dfs`, `priority`, and `adaptive`) via a shared `Expander` engine.
- **Candidate and wordlist encoding (`--encode` / `-E`)** — added `--encode` support to `scan` and expanded `fuzz` encoding to support both candidate-scoped (`base64`, `url`, `doubleurl`) and wordlist-scoped (`wl-base64`, `wl-url`, `wl-doubleurl`) encoders.
- **`--connect-timeout` for `fuzz`** — added TCP connection establishment timeout configuration (default: `3s`), achieving execution option parity with `scan`.

### Changed

- **Redirect filtering semantics** — status code matchers and filters (`--mc`, `--fc`) now strictly evaluate the final HTTP response status after redirect traversal, preventing intermediate redirect codes from producing false matches.
- **Fuzz `--quiet` parity** — `--quiet` (`-q`) in `fuzz` now outputs only discovered URLs in plain text mode, harmonizing behavior with `scan`.
- **Candidate search space accounting** — total candidate metrics in progress and summary reporting preserve the full search space accounting without dropping non-redirecting candidates.

### Fixed

- **SemVer prerelease comparison** — fixed SemVer precedence comparison in `internal/semver` to prioritize major, minor, and patch numbers before prerelease identifiers. Newer development and prerelease versions (such as `v0.7.0` or `v0.6.2-dev` compared to `v0.6.1`) are now correctly recognized as up to date rather than falsely reporting `DOWNGRADE REQUESTED`.
- **Fuzz redirect response reporting** — fixed fuzz workers incorrectly preserving intermediate 3xx status codes and initial requested paths; workers now report the terminal response status code and effective redirected URL.

### Removed

- **Obsolete CLI flags** — removed deprecated `--url-file`, `--filter-code` (use `--mc`), `--include-header` / `--exclude-header`, and `--tech`.

### Testing / Internal

- Added comprehensive regression test suites for `--only-redirects` in `cmd/only_redirects_regression_test.go` and `cmd/only_redirects_test.go`.
- Added extension expansion tests across traversal strategies in `internal/extensions/expander_test.go`, `internal/fuzz/expansion_test.go`, and `internal/recursion/expansion_test.go`.
- Added encoding integration tests in `cmd/fuzz_encode_test.go` and `internal/encode/encoder_test.go`.
- Added SemVer comparison and version check tests in `cmd/version_test.go`, `internal/semver/semver_test.go`, and `internal/update/update_test.go`.
- Added CLI cleanup regression tests in `cmd/cli_cleanup_test.go`.
