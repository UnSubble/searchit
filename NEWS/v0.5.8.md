# Searchit v0.5.8

Release Theme: UX, Terminal Experience & Reliability

Searchit v0.5.8 is a polish-focused release that significantly improves the command-line experience, output pipeline, terminal interaction, and overall reliability while preserving Searchit's deterministic scanning model.

### Highlights

- **Output Pipeline Redesign**: Completely redesigned the output pipeline around strict UNIX semantics. Human-readable information is consistently routed to stderr while serialized findings are written exclusively to stdout (or -o output files). Removed legacy output buffering and `--log-count`. Unified formatter execution across Text, JSON, NDJSON, CSV, and Markdown.
- **Improved Terminal Experience**: Redesigned the live progress interface. Recursive scans now display deterministic runtime activity instead of misleading percentage estimates. Standard scans and fuzzing retain exact progress reporting. Simplified the interactive Statistics view. Numerous rendering and synchronization fixes for interactive terminal mode.
- **Networking Improvements**: Added automatic protocol detection for targets without an explicit scheme. Attempts HTTPS first, falling back to HTTP only when appropriate. Added `--http-version` to explicitly select the HTTP protocol version.
- **Redirect Presentation**: HTTP 3xx responses are now rendered using dedicated redirect formatting in text output. Redirect destinations are displayed using the Location header instead of response body size. Structured output formats remain unchanged.
- **CLI Improvements**: Introduced condensed `--help` output focused on common options. Added `--help-all` exposing the complete command reference. Improved overall help organization and usability.
- **Reliability**: Improved cancellation behavior for Pause (`p`), Stop Target (`q`), Abort All (`a`), and `Ctrl+C`. Fixed multiple edge cases affecting output synchronization, formatter consistency, and interactive rendering. Improved embedded wordlist handling and fuzzing consistency. Verified deterministic behavior across scan, recursive scan, and fuzzing modes.

### Validation

Searchit v0.5.8 has been validated through:

- Full unit test suite
- Integration tests
- Race detector (`go test -race ./...`)
- Interactive terminal validation
- Formatter verification (Text, JSON, NDJSON, CSV, Markdown)
- Benchmark comparison against other directory and content discovery tools
