# Searchit v0.5.7

Release Theme: Profile System & Composition

Searchit v0.5.7 introduces the long-awaited Profile system, allowing complex configurations to be saved, shared, and composed directly from the command line.

### Highlights
- **Profile System**: Reusable configurations for scan and fuzz commands.
- **Command Import**: Create profiles effortlessly from existing CLI commands (`searchit profile create -h`).
- **Profile Composition**: Stack multiple configurations using a canonical, comma-separated profile syntax (e.g., `-p base,auth,paranoid`).
- **CLI Polish**: Cleaner help text, stricter namespace validation, and consistently excellent diagnostics for incorrect profile usage.
- **Reliability Improvements**: Improved profile error reporting, dependency visualization (`explain`), and reduced duplicate CLI parsing logic.
