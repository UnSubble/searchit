# Searchit v0.5.9

Release Theme: Engine Accuracy, Traversal Reliability & UX Polish

Searchit v0.5.9 focuses on traversal engine stability, metric accounting accuracy, user experience enhancements, and response presentation.

### Added

- Added `-R, --human-readable` to display response sizes using human-readable units (KB, MB, GB, ...). By default, sizes continue to be displayed in raw bytes.

### Improved

- Improved recursive traversal stability across BFS, DFS, and Priority strategies.
- Improved recursive scan behavior and recursion policy (`--recurse-on`) UX.
- Improved adaptive fuzzing output and live result rendering.
- Improved progress rendering, ETA calculation, and runtime statistics consistency.
- Improved response size reporting.
- Improved output pipeline consistency for terminal and file output.

### Fixed

- Fixed premature DFS traversal termination.
- Fixed candidate accounting and summary statistics.
- Fixed findings/progress inconsistencies.
- Fixed recursive scan metrics and progress reporting.
- Fixed terminal rendering issues during adaptive discovery.
- Fixed stdout, quiet mode (`-q`), and output file (`-o`) interaction.
- Fixed several recursive traversal accounting and reporting edge cases.
